## 初步集成检查的解释

真实 EMG 有界运行的两步 loss 分别为 `1.225229024887085` 和 `1.0683890581130981`，梯度范数分别为 `4.214742660522461` 和 `2.8672876358032227`。两步只说明当前样本可完成优化，不支持收敛或泛化结论。该运行没有评估最终测试集；其重载后两次验证报告的 SHA256 均为 `996158d3a96b1e983b54c09528ca55fecb7e11b7e7dc3fe3133a4d765acba9f6`。这些结果早于正在进行的最终 provenance 修复，修复后必须重新核验。

[脱敏集成证据](../results/integration-evidence.json)仅保存合成 GPU 检查、少量真实数组有限值审计与协议数量。它刻意不将上述尚待最终版本复核的真实 smoke 固化为验收结果。真实数组审计检查了 6 个单手样本的形状、有限值和有效标签计数；不等于扫描了全部数据行。

## 已落实的协议

独立 sidecar 保留固定 episode 网格上的官方测试中心，并按真实 `frame_split_id` 名称解析 User / Gesture / Both。验证区间从足够长的官方训练连续区间尾部确定性留出；训练窗口必须完整落在保留区间，短区间不会被强行切成不可用验证集。双手共享该 sidecar。

新训练按最终训练窗口覆盖的唯一行计算归一化，并用独立验证选择检查点。检查点包含继续训练状态与所选最佳状态；有界验证结果不能直接参加完整验证的选模竞争。训练会记录配置、源码、数据 receipt、划分和归一化身份，避免在恢复时默默改变输入。

## 尚未解决的科学边界

1. **数据与标签版本：** legacy release、论文 v1 与当前上游描述未证明逐项等价。41 人数量一致不足以证明生成标签或预处理一致。
2. **滤波依赖：** 初始实验使用整 episode 预过滤 EMG；无窗口交叠不能消除 FFT 引入的跨时间分区依赖。严格隔离需要原始 EMG 分区过滤及边界丢弃。
3. **架构与配置：** 主 EMG 采用发布兼容 12,000 点输入；论文 7,790 点设置另行研究。清洁融合采用 8 通道分支，并记录与发布 16 通道检查点及零残差初始化之间的差异。
4. **视觉完整性：** LMDB 是否覆盖目标中心、缺失 crop 比例及发布的视频帧对齐质量须据真实数据核验。适配器保留缺失 key 样本并单独报告，不能只挑有图样本作无声明对比。
5. **定量结论：** 合成 loss 有限或显存可容纳不证明真实数据训练收敛。所有真实训练、验证选模、重载和最终测试完成前，论文 MAE 仅作参考。
