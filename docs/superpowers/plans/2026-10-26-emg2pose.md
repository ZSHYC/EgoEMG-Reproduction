# EMG2Pose S/M/L Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 接通完整保真、可审计的 EMG2Pose 数据与官方 S/M/L，先完成真实 mini 的工程验收，再独立完成全量训练与 Tables 11/13。

**Architecture:** 在独立的 `emg2pose_*` 模块中直接把官方 HDF5 转为当前官方 memmap/metadata 协议，复用未改动的官方 dataset、transforms、模型和 Lightning 损失。数据盘点与转换由同一个小模块承担；工程短检查、官方字面评价、严格隔离审计各有明确身份。现有 EgoEMG 训练源码和四模型产物保持原样。

**Tech Stack:** Python、h5py、NumPy、PyTorch 2.2.2、Hydra/OmegaConf、pytorch-lightning、pytest；全量阶段使用 A800 与动态存储准入。

**Spec:** `docs/superpowers/specs/2026-10-26-full-paper-reproduction-design.md`

## Global Constraints

- 当前官方版本固定 `f7cbd048b7092139852270491d3859cd472e0311`；有歧义优先官方代码。
- 既有四模型结果和运行身份不得覆盖。
- 配置存在、短训练和测试通过不能代替完整实验。
- 新实验不得根据测试结果调参或选模。
- 不发布数据、原始参与者身份、凭据及无授权资产。
- EMG2Pose 保留 16 通道原始 EMG、20 角弧度标签、float64 时间戳和所有样本；无腕角补零、左右手复制、通道插值或新滤波。
- mini 原始 split 不变。若 mini 无 train，只能记录 `engineering_only=true`、真实 `optimization_source_split`；不得称独立 train/val 或正式模型。
- 全量验收必须覆盖官方 CSV 的全部 25,253 个唯一 filename；mini、完整前缀或可压缩子集均不等于全量。

## Review Focus

- 重复 session 字符串不等于重复文件：filename 是物理文件唯一键，session 原值必须保留；测试跨 generalization 的同 session 实例。
- 任一缺字段、截断、CSV/attrs 冲突、非法路径或未完成转换均须拒绝正式训练，不能依赖官方 loader 的宽松 fallback。
- 官方先增强后归一化，归一化为 float32 `(emg-0)/(18.49+1e-6)`；不能复用 legacy 的训练均值/方差或只做 rotation。
- `skip_ik_failures=false` 的训练验证窗口与官方离线评价的 `true` 窗口不同；全 False mask fallback、非有限标签和跨 chunk valid block 必须实测。
- checkpoint 重载必须严格匹配 20D/16ch、配置和数据身份；工程模型、旧版发布权重、训练末轮不能冒充全量独立验证选出的 best。

## 固定官方契约

来源：`upstream/config/experiment/emgformer/emg2pose_emgformer_{small,middle,large}.yaml`、`config/base.yaml`、`config/datamodule/egoemg.yaml`。已实际 Hydra compose；参数量为 CPU 构造所得，尚无前后向或训练证明。

| 字段 | S | M | L |
| --- | --- | --- | --- |
| 输入 / 标签 | 16ch / 20D | 16ch / 20D | 16ch / 20D |
| context / 轨迹长度 | 510/0 / 7,280 | 同左 | 同左 |
| window_length | 7,790 | 7,790 | 7,790 |
| train stride / jitter | **3,900 / true** | **780 / true** | **780 / true** |
| val/test datamodule stride / jitter | 7,790 / false | 同左 | 同左 |
| epochs / batch / seed | 250 / 320 / 42 | 同左 | 同左 |
| decoder dim / heads / layers / FFN | 256/4/3/512 | 256/8/6/1024 | 384/12/8/1536 |
| 参数量（含 head） | 3,481,636 | 6,638,884 | 16,342,308 |

共同配置：AdamW lr=0.001、weight_decay=0.01、betas=(0.9,0.999)、eps=1e-8；epoch cosine 至 1e-5；bf16-mixed、clip=1；非因果 decoder、initial pose=false；padding=(0,0)、不重复 dataset；默认 12 workers、session shuffle（16 batches/block）。S 的运行时 `skip_fields=[time]` 不授权删除持久源时间戳。选模监控官方 `val_mae`、mode=min、top3+last；另保存 count-weighted 统计以审计，不能互换两个聚合器。

训练增强按官方 `emgformer_regression_aug_best` 原顺序：ExtractField → Rotation(-1/0/+1) → ToFloatTensor → channel mask(p=.25) → time mask(num_masks=0) → frequency mask(3, max128) → Gaussian noise(p=.5, SNR25–35dB) → dataset 内 per-dataset normalization。val/test 只 ExtractToTensor 后归一化，不做随机增强。
