# 原生统一中心评价执行补充

执行依据为已批准的[全文设计](2026-10-26-full-paper-reproduction-design.md)要求4、7及用户的官方代码优先规则。本补充落实原有同帧评价要求，不改变整篇论文目标，也不重开已关闭的模型数学、旧表格或旧组件审查。实现者继续当前分支内联执行；常规实现和服务器运行沿用已有授权。

实际[来源核验](../../../results/native-table10-source-audit/README.md)证明：三种原生200轮EMG点报告的2792请求与原生视觉4306请求中心交集为0；既有报告不能拼成同帧Table10。固定官方 `center_frame.collect_val_centers` 在实际数据上的7790参考网格为4306手请求。统一要求12000窗口可容纳时为4282，Gesture/User/Both为2314/1646/322，排除24边界请求，且所有4282已有视觉目标。第二个独立进程从冻结episode元数据复算并验证全部计数。

比较过的路径：直接重排旧点报告不能创造缺失预测；重训成同一窗口会改动官方训练配方；采用固定官方参考网格，在既有选定权重上新增完整评价能保留训练身份并实现实际同目标。按现有授权选择第三条，12000只由所有参与模型的最大已训练窗口决定，与测试误差无关。仍需明确这是可得旧版数据上的统一人口评价，不是已证明的PDF作者人口。

实现保持官方完整collect_val_centers函数、原EMG纯点取样方法、冻结归一化、raw-token中点预测、22角和generated mask。当前纯EMG legacy view调用helper融合取样路径会缺图像字段，故适配层使用同一官方类已有的 `_getitem_center_supervised_emg`。不得更改官方源码，不能把异常静默跳过或缺失crop当成排除条件。完整4282请求全部保留，标签无效请求仍记录；mean与SD只在明确的有效误差分母上定义。

复用原生S/M/L的200轮、25000更新、验证BEST169/124/142及原检查点和构造身份。新评价采用官方center helper默认FP32、不autocast；旧BF16点与轨迹结果分列。无训练、优化器构造、数据增强、检查点重选、测试调参或新增架构家族。完整本机/服务器源码、输入、权重、人口和配置身份必须绑定；CPU工程探针和短资格不充当完整结果。

交付为新的原始单次消费预测、完整独立新进程重放、目标/掩码/身份与已有视觉第一遍逐请求连接、既有point reducer的逐用户mean±SD及pooled角度/有效样本总体、原生官方逐手float32均值旁证、独立退出后CPU读取、公开Table10及PDF显示值差异。因每个有效样本恰有22角，总体有效角pooled与有效样本mean应一致；原生batch加权统计另列。作者聚合、标签与人口等价仍须单独核验。

准入沿用CPU2、可用RAM128GiB、数据盘225GiB余量；GPU须实际稳定空闲且64GiB可用，运行至少8GiB余量；不得影响其他人的作业。所有权按PID+start_ticks核验，观察超时不是失败，不自动重启。仅在完整源/新组件验证和一次新组件审查后部署完整模型评价，已有审查与原模型套件不重跑。未完成下述任何交付均不得把Table10或全文标成完成。
