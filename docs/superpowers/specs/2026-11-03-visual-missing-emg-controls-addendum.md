# 视觉缺失与 EMG 贡献的受控评价补充

执行依据是用户 2026-11-03 明确要求“在复现的同时……重点关注在视觉部分有缺失时，emg是否真的能够有作用”，以及已批准[全文设计](2026-10-26-full-paper-reproduction-design.md)要求4/7。延续现有内联执行、服务器实验授权及官方代码优先规则，不重新训练或选择检查点，不替代全文其它义务。

既有[ViT-S 同帧缺图分析](../../../results/visual-missing-emg/README.md)显示179个有效缺图请求的融合平均收益0.4115°，但84改善／95变差，不能据此断言融合有效利用EMG。不同模型之间比较、同一模型输入消融、另行训练带缺失增强的模型是不同证据；本补充采用第二种以固定权重隔离输入变化，既有第一种结果保留，第三种会改变训练任务，暂不启动。

固定完整原生已选定ViT-S+S和RN18+S，各保持其真实三生产者、配置、FP32 eval、原图像归一化、7790/12000窗口及17168/11114原中心网格。原完整数据、目标、标签和自然crop有效标志全部保留，不以误差挑选样本。控制条件是补充实验，不属于原论文宣称已经复现的指标。

每个相同请求使用以下2×3条件：视觉为原始图像或完整缺图；EMG为真实对齐、归一化后全零、同窗口沿时间维循环移动 `window_length//2`。全零与固定官方 `mid_fusion.py` 的 `force_zero_emg` 输入语义一致，不能解释成原始电压为零或正常静息；包含布局填充通道。时间错位保留原窗口数值、通道和原边际分布，不跨手／用户／split拼接，不使用标签或随机数；它仍保留信号信息并产生人工接缝，不能声称等同随机独立EMG或完全去除姿态信息。

完整缺图按原 `_getitem_center_supervised` 返回缺crop的语义：逐通道 `(0-vision_mean)/vision_std` 的float32黑图，`vision_valid_mask=false`，原标签mask不动；均值和std来自实际冻结native view而非猜测的[0,1]图像常数。对纯视觉与融合使用相同退化图像。输入变换不修改原batch、文件、模型配置（包括force_zero_emg字段）、模型权重、BN或全局RNG。

对齐条件在新流程中须与已验收的原始完整预测精确连接。完整控制输出保存原始预测／目标／两个原生mask、原始自然缺图标志、完整键和每条件身份；独立新进程重放，禁止以少量接口检查或短资格替代完整结果。无优化器或训练更新；CPU2／可用RAM128GiB／磁盘225GiB保护，所有权按PID+start_ticks；不影响原RN18密网格流程、RN152训练和其他用户作业。

报告原有效标签人口、自然遮挡分层和真实缺图子集，分别给真实EMG相对置零／错位的配对误差差、胜负／分位数、逐split／手／录制与用户分组。所有条件中无效标签仍记录但不参与有效误差分母；人工缺图不得被新的vision mask排除。区分“对EMG输入敏感”“对齐EMG带来平均改善”“跨人稳定补偿”三个强度，按分组相关性给出适当不确定性后才作推断。官方中心窗口交叠、旧版数据与PDF等价限制继续披露。

本补充是基于现有授权的执行细化，不修改已有结果，不宣称全文或鲁棒性验证完成。[输入干预／真实原生forward边界45项检查](../../../results/visual-missing-emg/input-and-native-control-engineering-20261103.json)已通过，两个真实模型族／双手／六条件的单请求接口调用完成；正式batch64资格及完整控制实验尚未运行。后续实现完整流程，完成一次新组件审查及实际完整资格后部署。
