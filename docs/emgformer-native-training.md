# 原生 EMGFormer 训练入口与中心验证

S/M/L 训练入口保留官方 200 轮上限、batch 500、六 worker、BF16、seed 42、AdamW 5e-5、cosine T_max 200 / eta_min 1e-5、有效指尖损失 0.02 及全部原回调。ModelCheckpoint 按 val_mae/min 保留 top3/last；EarlyStopping 保持 patience 200。完整有限训练必须实际完成 200 轮，短程检查不能被标记为完整训练。

训练读取完整22×12000目标，验证保持22×1中心目标和长度1的原标签掩码。观察器在同一次原生模型前向中取得实际完整预测，核对 Lightning 返回的预测确实是原输出的中心切片，目标和掩码与原批次精确相同；不额外执行模型前向或重新对齐上下文。此前融合初始化的150轮/batch260/零worker/完整验证轨迹/0.01属于另一实验。

[一次独立审查与修复](../results/native-emgformer-train-final-review-20261029.json)发现一个重要问题：结果文件落后于完成的检查点时，恢复入口及独立读者可能接受缺失原始优化器、调度器和循环状态的文件。共享校验现用于续训构造模型前、完成结果发布前，以及last和选优检查点的独立读取；核对参数顺序与覆盖、AdamW全部状态/步数/配方、cosine进度、原循环及回调、原始epoch和随机状态。保存时另记录模型、优化器、调度器、回调、fit循环和随机状态六域内容摘要，拒绝有限值的静默篡改。保留原生保存边界：两轮检查点epoch进度processed=2、completed=1，不能人为改成两者都2。未改动已关闭的运行工厂、读取器或完整数据组件。

54项last/选优检查点删除和篡改测试先实际失败，随后完整新训练入口测试73项通过（153.92秒，14项上游弃用警告）。测试还覆盖三种规模配方、实际双手训练/中心验证/新进程恢复、原生best选择、作用域与覆盖拒绝、完成后拒绝重训、零新增更新的完成检查点恢复，以及无需构造模型的原始状态校验。原始AdamW中的OmegaConf betas仅在比较视图转为列表，检查点与优化器保持原样。一次修复完成，无再次审查或重跑旧95/58/59项组件测试。

[修复后服务器证据](../results/native-emgformer-train-review-fixed-cpu-20261029.json)绑定源码44b72b6：前缀33.521秒实际2更新，新进程续训33.516秒再2更新，第三进程2.970秒独立重开检查点、0模型/0更新。所有阶段实际退出0，八个记录的拥有进程均退出，98个冻结成员及16个合成输入文件九项属性未变。真实Small参数3,460,134、双手平衡原ID 0、1、170、171、训练22×12000/验证22×1及0.02有效权重均已核对；原始AdamW覆盖110个参数状态，调度器last_epoch=2。六个父状态域恢复精确一致，续训前冻结验证精确一致。[修复前8498910证据](../results/native-emgformer-train-cpu-20261029.json)保留为历史，不能代替当前源码证据。
