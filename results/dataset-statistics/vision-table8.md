# Table 8：七种视觉模型的实际配置与参数

本表对照所附论文第22页与固定官方版本`f7cbd048b7092139852270491d3859cd472e0311`，保留论文原值和本项目实际值。[JSON](vision-table8.json)保存来源摘要、原始整数、预训练身份和差异字段，[CSV](vision-table8.csv)提供七行对照。这是配置与参数分析，不新增训练成绩或已完成实验数。

[完整形状清单](vision-table8-inventory.json)公开七个实际实例的张量名称、形状、类型、parameter/buffer角色与冻结标志，不含权重值或样本。可以仅用Python标准库重新计算总参数和可训练参数：

```python
import json, math
with open('results/dataset-statistics/vision-table8-inventory.json') as f:
    inventory = json.load(f)
for model, item in inventory['models'].items():
    params = [s for s in item['state'].values() if s['role'] == 'parameter']
    total = sum(math.prod(s['shape']) for s in params)
    trainable = sum(math.prod(s['shape']) for s in params if s['trainable'])
    print(model, total, trainable)
```

计数覆盖实际注册参数，包含22角回归头，排除BatchNorm持久统计等buffer与已移除的ImageNet分类头。原始tensor元素数不能直接当作参数数。头部四个参数张量按`(d+1)×512+(512+1)×22`独立核对。ResNet三个已完成best检查点的完整SHA与原公开报告一致，九项文件属性保持不变；另用实际AdamW一阶矩的数量与形状独立核对全部可训练参数，避免把buffer算进模型大小。

ViT三行从已保留的原工厂构造身份中的`parameter_names`和`model_schema`逐张量计数，S/B配置身份与完成报告的训练协议一致，L使用实际完整训练身份。原包装层向timm传入`img_size=256`、`num_classes=0`；三者实际位置嵌入分别为`[1,325,384/768/1024]`。因此应使用该实例的参数数，不能直接套用预训练时518输入的模型宣传数字。[七模型结构来源](vision-fusion-architecture.md)与本次三份原包装源码摘要精确相符。

WiLoR保留的六个原生pose/shape/camera嵌入与解码部件共有52,499个冻结参数；计入总参数，排除于可训练参数。原模型构造实证见[CPU模型记录](../wilor-native-model-cpu-20261028.json)。其输入crop仍为256×256，包装层沿高度取`32:-32`后，实际骨干输入192×256；池化向量与回归头输入都是1280。论文的1576不能替代实际代码维度。

实际配置的解释：

- 固定官方`vision_resnet18.yaml`本身使用1e-4，与PDF的1e-3不同。三个已完成ResNet实验保留各自legacy配方：0.01指尖损失、150轮、单rank、4个读取进程，初始学习率亦经保存的AdamW参数组核对。RN50/152由RN18配方显式派生，官方没有对应独立YAML；这不等于它们已经完成新的0.02官方字面实验。
- ViT-S使用固定官方S配方；B/L显式继承S配方并改骨干，因此保留360批量，不能声称采用PDF的160/50。三者使用原生0.02有效指尖损失、BF16、单rank、0个读取进程、`val_mae/min`与patience30；L使用已披露的非重入activation checkpointing。最大150轮允许原生早停，不能要求已完成S/B必须跑满150轮。[S报告](../original-vision/vit-small/README.md)、[B报告](../original-vision/vit-base/README.md)。
- WiLoR为基于官方包装层的显式派生配方，0.02有效指尖损失、BF16、单rank、0个读取进程、30轮预算。初始学习率与余弦调度器`eta_min`均为1e-5，实际学习率保持常数。它在真实第6轮后因检查点持久存储不足退出，完整续训未开始；CPU恢复工程证明不算30轮完成。
- 通用ResNet/ViT的头使用ReLU，WiLoR使用GELU；全部是隐藏512、dropout0.1和22角输出。所有原配方、预训练身份与协议差异均保留，未因本表而修改任何模型或在运行任务。

ResNet-50的实际主干为23,508,032参数，按一位小数显示23.5M；加上1,060,374参数回归头后为24.6M。这提供一种可能的原表计数口径，但不能证明作者采用了该口径。ResNet-152实际主干58,143,808、完整模型59,204,182，与原表58.2M的准确原因仍未确定。JSON保留原值，未将其改写成“吻合”。

本次没有模型构造、前向、优化器创建、更新、CUDA或测试集消费；仅CPU读取已完成的ResNet检查点及保留的构造/运行身份。配置与参数对账不能证明论文的六张RTX4090批量口径、原始训练GPU-hours、原人口等价或七模型全部训练完成；未发布的独立配方与未完成实验仍列在[全论文清单](../../docs/full-paper-status.md)。
